# 井深对齐台

本地 Go/SQLite/SVG 深度对齐台，用于同一口井两个测井趟次之间的分段单调深度映射。页面可并排查看伽马（gamma）和电阻率（resistivity）曲线，拖拽硬/软锦标，查看局部伸缩率、成本分解、无数据区段和候选路径对齐差异。

## 数据口径

- 固定 fixture 在 `internal/fixture/fixture.go` 中确定性生成，不依赖外部数据。
- A 趟范围为 10–360 m；B 趟范围为 10–358 m。深度均向下增大。
- 两个趟次都有共同地层空缺：A 趟 185.5–189.5 m，B 趟 184–188 m。
- 曲线只保存实测采样点，空缺不使用零值或线性值填补；跨空缺的边没有数据相似度。
- 默认伸缩率范围为 `[0.75, 1.20]`，映射必须严格单调，不允许非零深度段压成一点。
- 硬锦标必须通过；两个硬锦标目标深度倒序时返回相邻的最短冲突链，不按创建时间丢弃。
- 软锦标可偏离路径，偏离量进入成本；自动建议与人工约束的冲突单独作为警告显示。
- fixture 含三个地层硬锦标、一对初始顺序交叉的人工硬锦标 `x1/y1`、共同空缺和两个未启用的自动软锦标（含与人工约束冲突的建议）。

求解器在 0.25 m 源深度网格、0.1 m 目标深度网格上做有界动态规划。一次运行保留三个候选路径：均衡、曲线形状优先、平滑伸缩优先。每个候选都保存数据相似、伸缩平滑、软锦标偏离三类成本，以及源井无数据边和逐曲线 RMS 对齐差异。

## 安装

```bash
go mod download
```

## 自动化测试与演示

```bash
go test ./... -count=1 && go run ./cmd/server --listen 127.0.0.1:5530
```

浏览器访问：

```text
http://127.0.0.1:5530
```

页面标题应显示“井深对齐台”。首次进入会自动运行固定 fixture：先看到 `人工对应 X -> 人工对应 Y` 的最短硬交叉冲突；在锦标卡片中停用（撤销）其中任一条后会自动重算并恢复求解。

## 操作与重放

- 拖动左右两侧三角锦标可调整 A/B 深度，拖放后自动重算。
- “停用（撤销）”用于临时取消人工约束；人工硬锦标可转为软锦标。
- “导出运行记录”下载 JSON bundle，包含当前数据集、操作流水、运行配置和所有候选路径结果。
- “导入记录”可恢复导出的 bundle，用于复核同一次运行。
- “重放操作”先恢复 fixture，再按操作流水逐条应用标记增改与启停，并按历史配置重放求解记录。
- “清空并恢复 fixture”清空 SQLite 后重新导入固定数据；也可以删除 `depthalign.db` 后重启，服务会自动重新建库和播种。

## HTTP API

- `GET /api/state`：当前曲线、锦标和最近一次运行。
- `POST /api/solve`：执行分段单调求解，请求体含 `min_stretch`、`max_stretch`。
- `POST /api/markers`：新增或更新带类型锦标。
- `POST /api/markers/toggle`：启用/停用锦标。
- `GET /api/runs`：运行历史，最新运行在前。
- `GET /api/export`：导出 JSON bundle。
- `POST /api/import`：导入 JSON bundle。
- `POST /api/replay`：从 fixture 开始重放操作流水。
- `POST /api/reset`：清空数据库并重新播种固定 fixture。

## 存储

默认数据库文件为当前目录下的 `depthalign.db`，可通过 `--db` 指定其他路径。SQLite 表包括数据集快照、操作流水和运行结果；服务使用无 CGO 的 `modernc.org/sqlite` 驱动。
