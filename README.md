# 井深对齐台

本地 Go/SQLite 服务，用确认的地层锦标、人工锦标和多曲线相似性建立两趟测井之间的分段单调深度映射。页面使用服务端返回的数据在浏览器中绘制 SVG，可并排查看自然伽马、电阻率，拖动非地层锦标，并切换候选路径查看对齐差异。

## 安装与演示

```bash
go mod download
go test ./... -count=1
go run ./cmd/server --listen 127.0.0.1:5530
```

打开 <http://127.0.0.1:5530>，页面标题应为“井深对齐台”。默认 SQLite 文件为 `wellalign.db`；不存在时自动创建并导入固定 fixture。

## 数据口径

- 深度单位固定为米；A 趟域为 1000–1100 m，采样间隔 2 m；B 趟域为 1030–1147.5 m，采样间隔 2.5 m。
- 曲线为确定性生成的 GR 与 RT；每条曲线只在自身有效样本范围内按该曲线 min/max 归一化后参与相似性。
- 共同无数据段为 A: 1051–1053 m、B: 1086–1089 m。数据库保存离散样本，不使用零值填补；相似性只在同一数据带内计算。
- 唯一允许的跨空缺路径是两端都落在空缺边界的“桥接”段：A 1050→1054 m 与 B 1085→1090 m 成对跨越，桥接段相似度为 0，不计曲线传播。
- 固定 fixture 含三个 active 硬地层锦标 `h1/h2/h3`、两个初始顺序交叉的 active 人工硬锦标 `x1/x2`、一个弱权重软锦标 `s1` 和两个 proposed 自动建议 `p1/p2`。
- 硬锦标必须精确通过；两个硬锦标顺序交叉或共用非零左深时阻断求解。冲突分析返回按硬锦标逆序边构造的最短冲突链，不依赖创建时间丢弃任意一方。
- 软锦标通过线性插值计算实际右深，按 `penalty × deviation²` 进入成本；候选保留相似性、软惩罚、正则和总成本分解。
- 映射的右深必须严格递增，任何非零左深段不能压成一点；段伸缩率默认允许 0.5–2.0，可在页面修改，硬锦标间超界会报告具体段落并阻断求解。
- DP 保留 3 条真实几何不同的候选路径。切换候选只改变查看的路径，不会改写原始约束；候选卡片显示与最佳路径的 MAD/最大右深差异。

## 验收路径

1. 清空或使用新的数据库后启动，页面先显示阻断冲突：最短冲突链为 `x1 → x2`，同时显示自动建议 `p1` 与人工 `x1` 的提示性冲突。
2. 在页面点击撤销 `x2`，系统重新求解并得到 3 条候选；成本分解含曲线相似性、软锦标偏离、正则项和 5 m 共同空缺桥接。
3. 点击“恢复固定 fixture”后撤销 `x1`，保留 `x2` 同样可解，证明两个交叉硬锦标没有按创建顺序被静默丢弃。
4. 候选路径中的无数据段固定从 `(1050,1085)` 到 `(1054,1090)`，空缺两侧的 GR/RT 形状不会跨无数据区形成低成本捷径。

## 操作

- 拖动红色/蓝色菱形可移动人工或自动来源锦标；地层硬锦标不可拖动。修改后自动保存并求解。
- 控制点表可撤销、恢复或确认自动建议；确认的自动建议转换为软锦标。
- “应用并重算”更新伸缩率范围、软锦标权重和候选数量。
- “导出运行记录”下载 JSON 快照，包含井次、曲线、控制点、自动建议、设置、全部 solve runs 和事件日志。
- “导入复核”上传此前导出的 JSON；也可点击“恢复固定 fixture”重新生成确定性初始状态。

## HTTP API

- `GET /api/state`：当前井次、约束、设置和最近一次求解。
- `POST /api/solve`：重新运行分段单调 DP。
- `GET /api/runs?limit=N`：历史运行记录。
- `PATCH /api/controls/{id}`：修改控制点深度、类型、状态或权重。
- `POST /api/controls/{id}/revoke` / `restore`：撤销或恢复约束。
- `POST /api/proposals/{id}/accept`：确认自动建议为软锦标。
- `PUT /api/settings`：更新对齐参数并重算。
- `GET /api/export` / `POST /api/admin/import`：快照导出与重导入。
- `POST /api/admin/reset`：恢复固定 fixture。

## 测试

自动化测试覆盖：

- 初始硬锦标交叉和最短冲突链；
- 撤销任一交叉人工锦标后的严格递增、可行伸缩率和硬约束通过；
- 共同空缺的成对桥接以及跨空缺相似性为零；
- 非零段零压缩、硬段伸缩率超界报告；
- SQLite 初始运行、撤销重算、导出、恢复 fixture、再导入复核；
- HTTP 首页标题、阻断/恢复 API 和快照导出。

运行：

```bash
go test ./... -count=1
```

生成的数据库和 WAL 文件可安全删除；下次启动会重新导入固定 fixture。
